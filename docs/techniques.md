# Techniques: 137 moves from 233 Opus 5.5 motion videos

Snapshot of [prompt-motion.com](https://www.prompt-motion.com/) taken 2026-10-09 (curated by [@p4nthera_](https://x.com/p4nthera_)). Every video in the gallery was made by Claude Opus 5.5 writing code. This page catalogues the moves that recur across them, gives an implementation hint for HTML + GSAP / HyperFrames, and links to the entries where you can see each one. The videos, prompts and credits live on each creator's entry page.

[简体中文版](zh/techniques.md)

## TL;DR

- **137 moves in 9 groups** — camera, transitions, typography, UI, 3D, data viz, particles, audio, render & QA — each with 2–4 linked examples. 181 of the 233 entries are cited.
- **The best transitions don't cut.** A continuity carrier, shared-element handoffs, one-shape morph chains and colour floods keep one object alive from scene to scene.
- **Numbers that move are the default data move.** Counters, count-ups or odometers appear in the catalog notes of 67 of 233 entries; a cursor in 39; particles in 51.
- **HUD chrome is everywhere, and contested.** HUD overlays, corner brackets or viewfinder frames appear in the catalog notes of 72 of 233 entries, while the one-line prompt shared by [#63 Claude self-intro motion graphic — @1littlecoder](https://www.prompt-motion.com/1littlecoder-9fef89) and [#215 Kinetic type self-portrait — @souravbhar871](https://www.prompt-motion.com/souravbhar871-61f424) asks the model to avoid exactly that.
- **Sound is specified like engineering.** 202 of 233 videos have audio; 7 prompts place every sound effect by its measured waveform peak, and all 8 prompts that name a loudness target pick −14 LUFS.
- **The craft that matters most is invisible.** 13 prompts require every frame to be a pure function of time (seek(t)), 7 render sub-frames for motion blur, and 4 scan the finished file for one-frame pops.
- **If you only take ten**, start with the "10 moves that make a SaaS launch film feel expensive" at the end.

## How to read this

- Each row is one technique: what it is, how to build it (HTML + GSAP / HyperFrames hints; the ideas port to Remotion or Canvas), and 2–4 examples.
- `#N` is the entry `id` in [catalog/catalog.json](../catalog/catalog.json). The first mention in each section carries the title and creator; later mentions are short links. Every link goes to the entry's page on prompt-motion.com.
- An example with no tag is visible on screen. **prompt** means the move lives in the prompt text — render, audio and QA moves rarely show in a still. **skill** means it is documented in the linked skill repo.
- Examples were checked against frames from each video. Prompt quotes are short, attributed, and linked to the creator's post.
- No per-entry quality scores are used here. The project's scores came from AI graders viewing a 6-frame contact sheet plus the prompt, with about ±1 point of noise between graders, which is why per-entry scores are not published.
- Counts such as "72 of 233" are case-insensitive keyword matches on the catalog's tags and technique notes (or on the prompt text, where stated). They count entries, so a prompt posted by two accounts counts twice.

## 1. Camera

One world, one camera. Most of the strongest camera work in the set moves a single container instead of cutting between scenes.

| Technique | How to build it | Examples |
|---|---|---|
| **One-take world camera** | Put the whole film inside one `.world` container; every shot is a tween of its x / y / scale, with scale interpolated in log space (tween a `logScale` proxy, apply `Math.exp`). One camera move at a time; scenes connect because objects transform, not because you cut. | [#5 Photo print app launch film — @twoclipping](https://www.prompt-motion.com/twoclipping-221cab) (one continuous take)<br>[#2 Shape morphing through UI states — @twoclipping](https://www.prompt-motion.com/twoclipping-5cba86) (camera zooms so each UI state fills the square)<br>[#52 Food craving launch film — @ultimaxbt](https://www.prompt-motion.com/ultimaxbt-2ddf1e) (prompt: one camera transform keyed as [time, zoom, x, y], zoom in log space)<br>[#178 Prompt Motion site promo — @antonio\_kodheli](https://www.prompt-motion.com/antonio-kodheli-490109) (prompt: one continuous camera over a single world layer) |
| **Click-zoom push-in (Screen Studio style)** | When the cursor clicks, ease the world from 1.0 to 1.2–3x around the click point and land the zoom on a strong beat; scale the cursor with it. | **Powers-of-ten zoom** | Nest several scales in the same world and push from 1x to 100x and beyond, swapping in a new layer of detail at each order of magnitude — or run it backwards until the product is a single star. | **Pull-back reveal** | Open on one full-bleed detail, then pull back to show it is one tile in a grid or one card in a collage. Animate the tile's corner radius to 0 at full-bleed (and back) so the match is exact. | [#178](https://www.prompt-motion.com/antonio-kodheli-490109) (a full-bleed reel pulls back into the first tile of the site grid)<br>[#159 Claude self-promo spot — @slvDev](https://www.prompt-motion.com/slvdev-64c45a) (pull back to a collage of use-case cards around 'Just ask.')<br>[#199 Shadow theatre home story — @x4b47x](https://www.prompt-motion.com/x4b47x-9cc84f) (the lit house becomes one of many in a village)<br>[#228 Scrabble tile character story — @Anilraok](https://www.prompt-motion.com/anilraok-eff262) (the camera rises to top-down and the 3D scene lines up with the app's UI) |
| **Push-through** | Push into a screen, the counter of a letter or a logo; the next scene lives inside. Three.js: a few camera presets on one scene and hard cuts between them. | [#43 Pelican riding a bicycle — @AxtonLiu](https://www.prompt-motion.com/axtonliu-0b861d) (wide → chain close-up → low hero angle → rear tracking)<br>[#202 First & 10 yellow line explainer — @blueoctopusai](https://www.prompt-motion.com/blueoctopusai-dd17bd) (stadium exterior → camera rig → field level, one 3D world reused) |

## 2. Transitions & cuts

The transitions people remember are the ones where one object survives the cut. Crossfades show up in the banned lists of several structured prompts (see section 9).

| Technique | How to build it | Examples |
|---|---|---|
| **Continuity carrier** | Pick one element (dot, ball, line) as the protagonist and give it a new job in every scene — the dot of a question mark, a cursor, a period, the logo. Every transition happens through it. Keep it as one DOM node outside the scenes and tween it across them. | [#126 Paper-style product launch film — @ik\_builds](https://www.prompt-motion.com/ik-builds-b8bdcf) (teal ball: bounce → hub of a node graph → chart point → logo)<br>[#81 Motion design showreel — @samuel\_spitz](https://www.prompt-motion.com/samuel-spitz-974923) (red line: underline → orbit ring → signature)<br>[#25 Orange dot motion system — @ultimaxbt](https://www.prompt-motion.com/ultimaxbt-bbebf5) (orange dot runs through every scene and the loop)<br>[#8 Engraving-style Claude ad — @LexnLin](https://www.prompt-motion.com/lexnlin-038035) (coral dot: '?' dot → period → pen tip → logo) |
| **Shared-element handoff** | The outgoing scene's object becomes the incoming scene's object. Tween the same node's position, size and radius across the boundary (FLIP; GSAP's Flip plugin fits) — never crossfade two separate nodes. | [#104 Taxtello bookkeeping app film — @daniel\_haida](https://www.prompt-motion.com/daniel-haida-8691d4) (a chart point carries the camera on; a receipt snaps onto its booking row)<br>[#66 Spotify product film — @brainextends](https://www.prompt-motion.com/brainextends-e19ac3) (the same cover art travels from search result to full-bleed)<br>[#52 Food craving launch film — @ultimaxbt](https://www.prompt-motion.com/ultimaxbt-2ddf1e) (the colour flood shrinks back into the chat bubble, carrying its words)<br>[#178 Prompt Motion site promo — @antonio\_kodheli](https://www.prompt-motion.com/antonio-kodheli-490109) (the closing reel contracts back into its grid tile) |
| **One-shape morph chain** | One rounded rectangle walks through every state by tweening width, height, border-radius and background; the content inside swaps with a short blur. Each morph is triggered by a cursor click. | [#2 Shape morphing through UI states — @twoclipping](https://www.prompt-motion.com/twoclipping-5cba86) (button → loader → player → slider → chart → ⌘K)<br>[#5 Photo print app launch film — @twoclipping](https://www.prompt-motion.com/twoclipping-221cab) (one black shape reports every order status)<br>[#111 Website analyzer product promo — @en\_\_\_\_\_\_ra](https://www.prompt-motion.com/en-ra-81c6dd) (one card becomes the input, the brand card and the result) |
| **Colour flood / circle wipe** | `clip-path: circle()` grows from an object's centre until it covers the farthest corner (end radius = distance to that corner) in about 0.3–0.35 s; hold, then contract into the next scene's object. | [#5](https://www.prompt-motion.com/twoclipping-221cab) (black circle floods edge to edge, then contracts into the next scene)<br>[#52](https://www.prompt-motion.com/ultimaxbt-2ddf1e) (lime flood from the wok on the drop)<br>[#114 AIsa API key promo — @0xfemyn](https://www.prompt-motion.com/0xfemyn-e114d3) (an orange circle swallows the tag cloud and opens on 'One key.')<br>[#201 Keyframe motion design reel — @Grace\_sunnyy](https://www.prompt-motion.com/grace-sunnyy-29bc61) (red iris expands into a full-frame wipe) |
| **Beat-locked colour-field cuts** | Swap the full-frame background on every bar, exactly on the downbeat. GSAP: `tl.set(bg, {backgroundColor}, beatTime(n))` — a `set`, not a `to`. | [#108 Kinetic type motion showreel — @\_topi\_003](https://www.prompt-motion.com/topi-003-9ca6b5) (red → cream → deep blue → blue → black)<br>[#217 Motion designer showreel — @TeslaChartz](https://www.prompt-motion.com/teslachartz-c58b32) (hard colour swaps every beat at 120 BPM)<br>[#89 Kinetic type showreel — @zheke](https://www.prompt-motion.com/zheke-38deff) (background hard-cuts every beat) |
| **Cut early, enter moving** | Put hard cuts 2 frames before the beat; each new shot is in motion from its first frame (an exponential ease-out that closes 12–19% of the gap on every frame), and shots leave on an acceleration or a blur ramp. Never cut on a still frame. | [#34 Frame by Frame launch video — @notdwd](https://www.prompt-motion.com/notdwd-7de38a) (prompt: cut frames placed 2 frames before the beat)<br>[#10 Launch video remake comparison — @notdwd](https://www.prompt-motion.com/notdwd-c2037d) (prompt: same rule; near-identical prompt) |
| **Dark-to-light act flip** | The problem lives in one luminance, the answer in the other; flip the palette in a single cut so the flip itself says 'here's the turn'. Keep the palette in CSS variables and `set` them. | [#103 Trezio app motion reel — @agonaliu\_](https://www.prompt-motion.com/agonaliu-466a8f) (dark problem collage → light 'Save anything.')<br>[#110 Product intro synced to music — @BogdanDragomir](https://www.prompt-motion.com/bogdandragomir-35e024) (ink-black to paper-white like an e-ink page refresh)<br>[#126](https://www.prompt-motion.com/ik-builds-b8bdcf) (paper cards invert to dark and wire up as a network)<br>[#96 DistilBook product explainer — @sudo\_kiran](https://www.prompt-motion.com/sudo-kiran-6609ed) ('Nobody reads' → 'But everyone watches' on a dark video wall) |
| **Stripe, slat and diagonal wipes** | Several rectangular `clip-path` strips slide across, staggered 40–60 ms — or one diagonal colour block sweeps the frame. | [#144 Studio website showreel — @andginja](https://www.prompt-motion.com/andginja-333d32) (vertical slat wipe reveals footage panels)<br>[#39 Claude motion design reel — @tequilafunks](https://www.prompt-motion.com/tequilafunks-97f6c9) (orange / blue / cream stripes wipe across)<br>[#150 Bento.surf product video — @bizibeast](https://www.prompt-motion.com/bizibeast-10f264) (yellow / blue diagonal colour-block wipe)<br>[#223 Risograph studio intro — @rneayan](https://www.prompt-motion.com/rneayan-474bcf) (diagonal-stripe and moiré wipes between cards) |
| **Dot-matrix dissolve** | Break the frame into a grid of dots and shrink or recolour them cell by cell, ordered by seeded noise or by distance from the centre. Canvas: one `arc` per cell, radius = f(t, cell). | [#211 AgentHud project motion video — @Jazzen\_Chen](https://www.prompt-motion.com/jazzen-chen-4542ae) (a dot-matrix wave sweeps across as the scene transition)<br>[#185 Nohandslabs brand promo — @robvjourney](https://www.prompt-motion.com/robvjourney-ce3e1a) (the pixel '95%' scatters into dots)<br>[#128 Flowdrive motion showreel — @manuelogomigo](https://www.prompt-motion.com/manuelogomigo-f33ca9) (scenes dissolve into dot particles) |

## 3. Typography

Kinetic type carries most of the message in these films. The recurring discipline: one accent per line, one caption system per film, and enough hold to read.

**Three pipeline habits that matter more than any single move**

1. Write the prompt as tagged blocks and end it with a stills gate: a beat map and four key stills before anything renders in full ([#5](https://www.prompt-motion.com/twoclipping-221cab), [#25](https://www.prompt-motion.com/ultimaxbt-bbebf5), [#52](https://www.prompt-motion.com/ultimaxbt-2ddf1e)).
2. Before the full render, export one still per beat or per cut; after it, scan the file for one-frame pops with a frame-difference pass ([#2](https://www.prompt-motion.com/twoclipping-5cba86), [#5](https://www.prompt-motion.com/twoclipping-221cab), [#38 Ora 2 image model launch film — @rossaxbt](https://www.prompt-motion.com/rossaxbt-3085b7)).
3. Have a fresh critic — an agent that did not build the film — review the render and fix what it finds ([#178 Prompt Motion site promo — @antonio\_kodheli](https://www.prompt-motion.com/antonio-kodheli-490109)).
