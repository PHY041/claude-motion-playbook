# 招式库：233 条 Opus 5.5 动效片里反复出现的 137 招

数据快照：[prompt-motion.com](https://www.prompt-motion.com/)，2026-10-09（策展人 [@p4nthera_](https://x.com/p4nthera_)）。画廊里每一条片子都是 Claude Opus 5.5 写代码做出来的。这一页整理这些片子里反复出现的做法，每招给出 HTML + GSAP / HyperFrames 的实现提示，并链接到能看到这一招的条目。视频、prompt 和署名都在各位作者的条目页上。

[English version](../techniques.md)

## 要点速览

- **9 组共 137 招**：镜头、转场、文字、UI、3D、数据可视化、粒子、音频、渲染与 QA，每招链接 2–4 个例子，共引用 233 条里的 181 条。
- **最好的转场不靠剪。** 一个元素贯穿全片、共享元素交接、一个形状一路变形、颜色淹没，都是让同一个物件从这一幕活到下一幕。
- **「会动的数字」是默认的数据招式。** 233 条里 67 条的 catalog 描述提到计数器、数字滚动或里程表；39 条提到光标，51 条提到粒子。
- **HUD 外框到处都是，也有争议。** 233 条里 72 条的 catalog 描述提到 HUD、角括号或取景框；而 [#63 Claude self-intro motion graphic — @1littlecoder](https://www.prompt-motion.com/1littlecoder-9fef89) 和 [#215 Kinetic type self-portrait — @souravbhar871](https://www.prompt-motion.com/souravbhar871-61f424) 共用的那条一句话 prompt，恰恰要求避开角落里的框和字。
- **声音按工程规格来写。** 233 条里 202 条有音轨；7 条 prompt 要求每个音效按实测波形峰值对齐，写了响度目标的 8 条全部是 −14 LUFS。
- **最要紧的功夫在画面之外。** 13 条 prompt 要求每一帧都是时间的纯函数（seek(t)），7 条用子帧做运动模糊，4 条在成片上扫描单帧跳变。
- **只想拿走十招的话**，直接看文末的「让 SaaS 发布片显得贵的 10 招」。

## 怎么读

- 每行一招：**中文名** + English name、怎么做（HTML + GSAP / HyperFrames 的提示，思路同样适用于 Remotion 或 Canvas）、2–4 个例子。
- `#N` 是 [catalog/catalog.json](../../catalog/catalog.json) 里的 `id`。每节第一次出现时写明标题和作者，之后用短链接。所有链接都指向 prompt-motion.com 上的条目页。
- 例子不带标记，表示画面上看得见；**prompt** 表示这一招写在 prompt 原文里（渲染、音频、QA 类招式很难从静帧看出来）；**skill** 表示写在对应 skill 仓库的文档里。
- 例子都对照视频画面核对过。引用的 prompt 原文都很短，注明作者并链接原帖。
- 本页不使用任何单条质量评分。项目里的评分来自 AI 评分员看 6 帧联系表加 prompt 打分，不同评分员之间大约有 ±1 分的噪声，所以不公布单条分数。
- 「233 条里 72 条」这类计数，是对 catalog 的标签和技法描述（注明时是对 prompt 原文）做不区分大小写的关键词匹配。按条目计数，同一段 prompt 被两个账号发过就算两次。
